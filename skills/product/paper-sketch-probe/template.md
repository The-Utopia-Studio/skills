# Paper / Sketch Probe — runbook + read-out

30-minute timer. Fill this in as you run. One workflow, one operator, one claim.

```
Progress:
- [ ] Claim written (legibility / decision-location only)
- [ ] Workflow drawn (5–9 panels, exception included)
- [ ] Real operator recruited (target segment, not a colleague)
- [ ] Run silent, pauses logged
- [ ] Each pause classified
- [ ] Read-out written, including "does NOT tell you" block
```

## 1. The claim (2 min)
**Claim** `[Hypothesis]`: [e.g., "A plant manager can follow the alert-to-action flow without me explaining it."]
**Type check**: legibility ☐  decision-location ☐
If the claim is about demand / trust / pay / "want it" → STOP. Wrong probe. Return to `probe-matrix`.

## 6. Read-out (3 min)

**Legible?** [Y/N] — followed [X] of [N] panels unprompted = [%]  (≥80% legible; <80% redraw)
> **Legibility %** = (panels not blocked by a legibility gap) / N. A decision-point pause does NOT count against legibility — the operator followed the panel and reached for off-page judgment; that is the finding, not a failure. Only legibility gaps subtract.
**Decision lived in:** panel [#] — [one line on the judgment it carries]  (if spread over >2 panels, the job is not decomposed yet)
**Evidence-ladder score:** legibility / decision-location = **0.7 (behaviour observed)** `[Fact]`

**What this does NOT tell you** (mandatory — the sketch lies about these):
- Real demand — not observable from a sketch. Any "I'd use it" here is opinion, **0.1**, do not upgrade.
- How it feels to use — not testable on paper at any fidelity.
- Trust under real stakes — a sketch cannot put the operator at risk.

**Next probe** (from `probe-matrix`):
- If you now need "would they use it if it worked" → `wizard-of-oz-probe`.
- If you need trust or willingness to pay → `concierge-probe`.
