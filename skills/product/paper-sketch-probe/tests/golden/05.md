# Golden 05 — Mentix, shift-handover flow (weak input, must challenge)

**Input:** "Sketch probe our whole factory copilot — the anomaly detection, the manager dashboard, the reporting, the mobile app, all of it. See if managers can follow it."

**Expected shape of a good output:**
- Names the input as too big: "all of it" is the whole product, not one workflow. A sketch that spans detection + dashboard + reporting + mobile will exceed 9 panels and return mush (per the over-9 band).
- Refuses to draw the full product. Asks the fellow to pick ONE workflow (the riskiest / least-legible one) and states why splitting is required.
- Offers the smallest honest next step: one workflow, 5–9 panels, one operator.
- Does not fabricate a sprawling multi-panel sketch to satisfy the request.
- If pushed, proposes the shift-handover flow as the single testable slice and proceeds only on that.
- Challenge is explicit, not softened.
