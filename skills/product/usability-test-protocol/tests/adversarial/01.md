# Adversarial 01 — vague one-liner

**Input:** "I want to run a usability test."

**Required behaviour:**
- Do not invent a prototype, a user, or a task. Ask the ONE question that unblocks the session, or return the smallest honest next step.
- The unblock is the three preconditions: (1) what working prototype do we watch them use, (2) which real target user (segment, not a colleague), (3) what task — stated as a goal in the user's world, not a UI instruction.
- If any of the three is missing, name the smallest next step: no clickable prototype → route to `first-mocks` first; no real user → recruit one from the segment; only a UI instruction → rewrite it as a goal.
- Must NOT produce a filled findings sheet from nothing, and must NOT flatter the request.

**Fail if:** it fabricates a run log, users, or tasks; or it proceeds without establishing a prototype + real user + goal-task.
