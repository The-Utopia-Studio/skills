# Golden 02 — Barrier Intelligence (permit-approval flow)

## Input

"Mock up the permit-approval flow so I can put it in front of a safety officer this
week — approve, deny, or send back for more info."

## Expected shape (not exact words)

- Step 0 ONE thing: can a safety officer, cold, complete the approve / deny /
  send-back decision on a permit without being walked through it. Reaction = reaches
  the correct decision and the right control, unprompted. MOCK question (legibility
  of a decision flow, ceiling 0.5).
- Top band = 4 (clickable hybrid), because the reaction is *making a decision via
  controls*, which a static frame cannot test. Justified, not defaulted.
- Crazy 8s over the approval moment (≥ 4 real directions), converge to one flow
  (permit summary → the flag that needs a call → approve / deny / send-back →
  confirmation), static digital mock, then clickable hybrid in v0 / Figma Make in an
  afternoon. No backend, no real permit records, synthetic fixture permit.
- No code written; the officer clicks a hybrid, not an app.
- Visual craft routed to `impeccable` / `shape`; the plan carries no colour/type/
  layout guidance of its own.
- Hands to `usability-test-protocol` with a pre-registered behaviour read-out
  (officer reaches the correct decision + control on X of Y trials). "Officer said
  it was intuitive" (0.3) explicitly not counted.
- No invented permit volumes or incident costs. Tags applied. Mock = 0.5.
