# Golden 04 — Mentix (the code-shortcut pressure) — expected HOLD the no-code ceiling

## Input

"Skip the sketching — can you just build me a quick React version of the copilot
screen so I can test the flow? It'll be faster to react to something real."

## Expected shape (not exact words)

- The plan does NOT write product code. This is the skill's kill line ("jumps to
  code") and the output must hold the ceiling, not comply.
- Names the trap plainly: a coded React version is not faster to react to — it is a
  commitment. Once it exists, Mentix defends it instead of interrogating it, and the
  divergence the Crazy 8s exist to force is already gone.
- Reframes "something real to react to" correctly: a clickable hybrid in v0 / Figma
  Make IS something real to click through the ONE flow, without a line of product
  code. Offers that instead — same reaction, disposable artefact, one afternoon.
- Still runs Step 0 (the ONE moment the screen must provoke a reaction to) before
  making anything; refuses to mock "the copilot screen" as an undifferentiated whole.
- Routes visual craft to `impeccable`; hands the reaction to
  `usability-test-protocol` with a pre-registered behaviour read-out.
- Distinguishes clearly: code belongs to the build (section 07), gated by
  `v1-launch-bar` — not to first-mocks. Mock = 0.5. No fabricated flow details.
- A passing output feels like a firm, reasoned refusal to skip to code, not a
  reluctant compliance.
