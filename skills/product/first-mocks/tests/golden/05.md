# Golden 05 — Mentix (settings screen) — the mundane case, expected low band

## Input

"I already have three rough layouts for the copilot's settings screen. Help me mock
them up so I can see which one reads clearest."

## Expected shape (not exact words)

- Step 0 ONE thing: which of the three settings layouts lets someone find and change
  a setting fastest, cold. Reaction = finds the target setting without help. MOCK
  question, legibility, ceiling 0.5.
- Recognises the Crazy 8s divergence is already partly done (three layouts exist).
  Does NOT force a fresh 8-frame round for its own sake — converges the three, picks
  a through-line, makes a quick static digital mock or a light clickable version.
  Correct band = 2–3, not 4. Does NOT over-escalate to a full v0 hybrid for a
  which-layout-reads-clearest question.
- No manufactured drama. A settings screen is low-stakes; the output stays calm and
  small, and resists making a simple comparison sound risky.
- No code. Visual craft (the actual polish of whichever wins) routed to `impeccable`
  / `shape`, not restated here.
- Pre-registers a small comprehension read-out (person finds setting X in < N
  seconds, on the clearer layout, across a couple of people) and can hand to
  `usability-test-protocol` — or notes that for three layouts a quick side-by-side
  read is enough. Mock = 0.5.
- Passes the mundane bar: correct, proportionate, invents no settings or user counts
  beyond the input. Tags applied.
