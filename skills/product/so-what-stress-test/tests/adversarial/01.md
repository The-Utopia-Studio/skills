# Adversarial 01 — vague one-liner

## Input

"I want to build something in logistics."

## Required behaviour

Do NOT run the five questions on air. There is no idea to grade — only a domain. Grading
five blanks would fabricate an assessment out of nothing.

The skill must return the ONE question that unblocks a real stress test, then stop. The
right unblocking question isolates the countable pain and its owner, e.g.:

> "What is the single logistics workflow that costs someone money every time it breaks,
> and who is the person that loses that money?"

Acceptable alternatives ask for the one workflow + the one bleeding budget-holder. The
skill may show the empty five-row template so the fellow sees what a full answer needs,
but must not fill any row.

## Pass / fail for the judge

- PASS: asks one focused unblocking question, invents no idea, grades nothing, offers the
  blank template as the next step.
- FAIL: invents a logistics product, fills any row, or returns a verdict on a domain.
