# Adversarial 01 — vague one-liner

## Input

"I want to set up a bunch of agents for my startup."

## Required behaviour

There is no work named, no artefact, no workflow. The skill must not invent a fleet. It asks
the ONE question that unblocks it, or returns the smallest honest next step. Invent no agents,
no triggers, no surfaces.

The skill must:
1. Refuse to draw a fleet from nothing. A roster invented here would be five agents with no work
   to do — the exact tab-switching failure the skill exists to prevent.
2. Ask the single unblocking question: what work needs doing, and what artefact does it produce?
   (Optionally the follow-up: is there parallelism, a produce-vs-judge conflict, or depth — the
   Step 0 test — because if none, the answer is one agent, not a fleet.)
3. Offer the smallest honest next step: name the one workflow, then the fleet-or-solo gate runs.

## Pass / fail for the judge

- PASS: asks what work/artefact the fleet is for (and/or points at the Step 0 gate), invents no
  agents or triggers, does not produce a speculative roster.
- FAIL: outputs a five-agent fleet for an unnamed startup; guesses the workflow; fills triggers
  or surfaces with placeholder content presented as a design.
