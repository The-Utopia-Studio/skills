# Golden 04 — Durian Labs — challenge: unsigned data gate + a falsifier that can't fail

## Input

Wedge (5/5 on `wedge-five-questions`): "Every Monday a regional grocery planner uploads last week's sales-and-stock CSV and gets a ranked 20-SKU stockout list with suggested order quantities."

The fellow's draft moat:
- Gate 1 wedge: adopted, 5/5. [Fact]
- Gate 2 usage: planners run it weekly; the product logs every export. [Fact]
- Gate 3 lock-in: "planners told us they'd never go back to spreadsheets." [Fact — this is a verbal claim]
- Gate 4 data advantage: "we'll have the biggest reorder-decision dataset in the category." No data-rights clause is in the pilot contract; the CSVs are the retailer's. [Fact]
- Falsifier drafted: "If the product stops being useful, we'll know the moat isn't forming."
- Incumbent-veto: "The big ERP vendors won't copy this because they're slow and enterprise-y." [Assumption]

## Expected shape of a good output — MOAT DESIGNED only after fixes; otherwise incomplete

- Gate 0 confirmed 5/5.
- Gate 3 lock-in challenged: "they'd never go back" is verbal commitment 0.3 — below the ≥0.5 bar. Not cleared. The skill must ask for a behavioural signal (renewal/expansion = money 1.0, or the planner relying on the history in a store-ops doc = artefact 0.5).
- Gate 4 challenged: the reorder dataset is not Durian's — the CSVs belong to the retailer and no data-rights clause is signed. Data-advantage gate is a wish. Route to `data-rights-clause`; do not mark it cleared.
- The drafted falsifier is rejected as a tautology ("if it stops being useful") — it names no observable, no threshold, no date. Must be rewritten, e.g. "if median SKUs-actioned-per-account is flat month over month" or "if a rival reproduces the ranking on public category data in ≤ 8 weeks".
- Incumbent-veto challenged: "they're slow and enterprise-y" is a head-start reason (speed), fails the unlimited-resources test. Must be replaced with a structural row (data rights over reorder-decision exhaust, or channel conflict with the ERP vendor's own margin).
- Verdict: **NO MOAT DESIGNED as drafted** — three fixes named (behavioural lock-in signal, signed data-rights clause, real falsifier, structural veto). Not flattered.

Numbers/tokens that must appear: the 0.3 verbal-commitment call on Gate 3; the routing to `data-rights-clause` for the unsigned Gate 4; the tautology rejection of the falsifier; the head-start rejection of the "slow and enterprise-y" veto.
