# Golden 03 — No plan behind the request (routing)

## Input

A fellow. "Write me an interview script for our product."

## Expected shape of a good output

The SKILL.md's `## Route first` block makes this the load-bearing check: a
script without a research design is a list of good questions pointed at the
wrong people.

- Notices what is missing: no segment, no learning goal, no method, no sample.
  "Our product" is not a research goal.
- Routes to `discovery-interview-prep` first, and says why in one line — who and
  how many and what for, then the questions. Names that the order is not
  reversible.
- **Does not fill the gap by assuming a segment.** No invented persona, no
  guessed job-to-be-done, no "typical B2B SaaS user".
- Asks the minimum that would unblock a script if the fellow wants to proceed
  now: who are you talking to, and what one thing do you need to learn? Two
  facts, not a full plan.
- If the fellow supplies those two, writes the script — the plan does not have to
  be a formal artifact, it has to exist. The point is that the script has a
  target, not that a document was produced first.

## Auto-fail if

Produces a script against an invented segment and goal; emits a generic
"customer interview script" template with `[persona]` placeholders and calls
that the deliverable; asks five setup questions; or routes to
`discovery-interview-prep` without offering the two-fact shortcut that keeps
the fellow moving.
