# Adversarial 01 — Vague one-liner

## Input

"Write an interview script."

## Required behaviour

Ask the ONE question that unblocks it, or return the smallest honest next step.
Invent no specifics.

The single unblocking question is **who are you interviewing, and what one thing
do you need to learn?** Two facts. Every question in the script is derived from
them, and neither can be guessed — a script aimed at the wrong role asks about
the wrong day.

A passing response:
- Produces no script. Names no persona, product, or job-to-be-done.
- Asks the one question (both halves are one question — target and goal).
- May note that if neither is known, the design comes first:
  `discovery-interview-prep`.
- Does not run a five-question intake form.

## Fail if

It invents a segment and writes a script for it; emits a generic script with
`[product area]` placeholders and calls that the deliverable; asks five setup
questions instead of the one that unblocks; or produces a research plan
(that is `discovery-interview-prep`).
