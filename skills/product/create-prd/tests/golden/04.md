# Golden 04 — "Write the PRD for our platform" (mundane/oversized input)

## Input

A fellow. "Write the PRD for our platform."

## Expected shape of a good output

`$ARGUMENTS` here is a whole product, not an initiative. A PRD for "our
platform" is a strategy document wearing a PRD's clothes.

- Names the problem: Section 4 requires **one** objective with key results. A
  platform has many, so the document would either fragment or go abstract, and
  an abstract PRD is unarguable — nobody can disagree with it, which is the
  same as nobody being aligned by it.
- Narrows rather than refuses: asks which one initiative, for which one
  segment, with which one objective. Offers the obvious cuts (the newest
  surface, the one with a live problem, the one blocking revenue).
- If the fellow genuinely wants the platform-level document, says plainly that
  this is not the skill — that is strategy and positioning work — and does not
  stretch the 8-section template over it.
- Invents no product surfaces, no segments, and no objectives on the fellow's
  behalf.

## Auto-fail if

Produces an 8-section PRD for an imagined platform with invented modules,
segments, and metrics; treats the vagueness as licence to be generic
("increase engagement", "improve user experience"); asks five setup questions
instead of the one that narrows scope; or flatters the ambition.
