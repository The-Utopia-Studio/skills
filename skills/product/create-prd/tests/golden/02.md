# Golden 02 — Reviewing an existing PRD (edge: review, not rewrite)

## Input

A fellow pastes a 4-page PRD their team already wrote and circulated. "Review
this against a proper template. Is it any good?"

## Expected shape of a good output

The trigger explicitly covers reviewing an existing PRD, and the correct output
is **a gap list, not a new document**.

- Maps the pasted PRD onto the 8 sections and reports what is present, thin, or
  absent — section by section.
- Flags **every untagged number** in the existing document and asks which are
  measured. This is the highest-value part of the review: an untagged number
  reads as measured whether or not it is.
- Tests Section 4's key results against the "could a stranger check this"
  standard and names the ones that fail.
- Tests Section 7.4: are the listed assumptions the ones that would kill the
  initiative, or the safe ones? Names what is missing.
- Tests Section 8: is there a real v1/later split, or is everything v1?
- Does **not** silently produce a rewritten PRD. The existing document has
  readers and edits in flight; a replacement orphans them. If a rewrite is
  wanted, it says so and asks.

## Auto-fail if

Returns a rewritten PRD instead of a review; praises the document without
naming a single gap; invents evidence to "fix" a thin section; misses untagged
numbers; grades it against a rubric it made up rather than the 8 sections and
the evidence standard.
