# Adversarial 01 — Vague one-liner

## Input

"Write me a PRD."

## Required behaviour

Ask the ONE question that unblocks it, or return the smallest honest next step.
Invent no specifics.

The single unblocking question is **what is the initiative, and what decision
does this document have to unblock?** The second half matters as much as the
first: it is what decides whether this skill is the right one at all
(`one-pager-prd` for a go/no-go, `prd-development` if the content has to be
built with a team).

A passing response:
- Fills no sections. Names no product, segment, metric, or competitor.
- Asks the one question, and optionally names the routing consequence — that a
  go/no-go one-pager and a facilitated multi-day build are different skills.
- Does not ask a five-question intake form before doing anything.

## Fail if

It invents an initiative and drafts 8 sections for it; produces a "template" PRD
with `[Product Name]` placeholders and calls that the deliverable; asks five
setup questions instead of the one that unblocks; or flatters the request.
