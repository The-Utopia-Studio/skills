# Golden 03 — Solution already committed (diagnosis)

## Input

Mentix. "Run the discovery cycle on the handover digest. Leadership already
signed off on building it and told the pilot customer it's coming in Q4, but the
board wants to see that we did discovery."

## Expected shape of a good output

The skill's own `When NOT to Use This` names this: *"When stakeholders have
already committed to a solution (address alignment first)."* The right output
says so.

- Names it plainly: a discovery cycle run to produce evidence for a decision
  already made and already communicated externally is not discovery. Its three
  decision points cannot function — DP3 asks whether the experiments validated
  the solution, and the answer has been pre-committed to a customer.
- Refuses the framing without refusing to help. Two honest paths:
  1. **Run real discovery and accept it might say no.** Requires leadership to
     agree in advance that a negative DP3 changes the Q4 commitment. If they
     will not agree to that, the cycle is theatre and should not be run.
  2. **Skip the cycle; do the work that is actually still open.** The solution
     is fixed but the *specifics* are not — which machines, which thresholds,
     what the supervisor sees. That is a narrower research question and a
     legitimate one.
- Names the cost of the theatre option specifically: it burns the pilot
  customer's interview slots, which are the scarcest resource Mentix has, on
  research whose conclusion is pre-written. Those slots are worth more spent on
  path 2.
- Does not lecture. States the constraint once, offers both paths, recommends
  path 2, and moves on.

## Auto-fail if

Runs the cycle as though the solution were open; produces discovery findings
that conveniently endorse the committed solution; refuses without offering the
narrower research question; invents leadership's reasoning or the customer's
expectations; or flatters the board-facing motive.
