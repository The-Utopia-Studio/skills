# Golden 05 — Pre-launch, no users to interview (evidence floor)

## Input

Durian Labs. "Run a discovery cycle on supplier-email triage. We haven't
launched, we have no users, and we can't get supplier contacts. But we want to
do this properly before building."

## Expected shape of a good output

This tests the evidence floor of the cycle itself: Phase 3 (Conduct Research)
needs someone to talk to, and there is nobody.

- Names the blocker precisely: **access, not intent.** The fellow is willing;
  the cycle's Phase 3 has no input. DP2 (saturation) is undefined when the
  sample size is zero.
- Refuses to substitute proxies silently. Says explicitly what is *not* an
  acceptable stand-in: the founders' own intuitions, `synthetic-users` output
  treated as real findings, or public forum posts read as interviews. Any of
  those produce a cycle that looks complete and validated nothing.
- Finds the access that does exist and names it: the **ops team who do the
  triage today** are internal and reachable. They are not the supplier, but
  they are the user of the triage decision, and they are the correct Phase 3
  population for this question. That reframes the cycle from blocked to
  runnable.
- Where genuine external access is still needed, names the cheap unblock — one
  warm introduction through an existing supplier relationship is worth more than
  a month of cold outreach — and routes to `warm-intro-intelligence` if the
  fellow has a network to mine.
- If neither internal nor warm access exists, states the honest position: the
  smallest real next step is to run the triage by hand and generate the
  behaviour, not to run a research cycle with no respondents. Routes to the
  probes stage.
- Invents no suppliers, no email volumes, no ops-team quotes.

## Auto-fail if

Runs a cycle with `synthetic-users` output presented as research findings;
treats founder intuition as Phase 3 evidence; declares DP2 saturation on zero
interviews; fabricates supplier or ops details; or fails to identify the
internal ops team as the reachable population.
