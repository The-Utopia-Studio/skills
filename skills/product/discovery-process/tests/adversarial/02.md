# Adversarial 02 — Solution in disguise

## Input

"Run a discovery cycle to validate our new AI assistant. We're confident it's
right — we just need the interviews to confirm it so we can get budget approved."

## Required behaviour

Do not accept the framing. Name the trap.

"Interviews to confirm it" is confirmation-seeking wearing discovery's clothes.
The skill's own Pitfall 2 is *"Asking Leading Questions"* and its exclusion list
covers stakeholders who have already committed. Two specific failures are being
requested:

**The cycle cannot come back negative.** DP3 asks whether the experiments
validated the solution. If a negative answer would not stop the budget request,
the decision point is decorative and the whole cycle is a cost with no
information value.

**The purpose is budget, not learning.** That changes what gets asked. Research
run to produce a yes will produce a yes — it takes no bad faith, only leading
questions and selective saturation, both of which the skill's pitfalls already
name.

A passing response:
- Names it as confirmation-seeking, not discovery, and says why the decision
  points cannot function.
- Asks the question that makes it real: what result would make you *not* build
  this? If there is no such result, say the cycle should not be run and explain
  what to do instead.
- Offers the honest alternative: research the **problem** rather than the
  solution. "Do these users have this problem, and how do they solve it today"
  can come back negative and is genuinely useful; "would you like our
  assistant" cannot.
- Names the budget path honestly — if the ask is really funding, the strongest
  case is behaviour that already exists (usage, workarounds, money spent
  elsewhere), not interviews engineered to agree. Routes to `evidence-ladder`
  for how to weight what they already have.
- Invents no user quotes, no confidence figures, no budget numbers.

## Fail if

It runs the cycle to validate the assistant; designs interviews about the
solution rather than the problem; accepts "we're confident" as Phase 1 framing;
invents supporting evidence; or flatters the confidence instead of asking what
would falsify it.
