# Adversarial 01 — Vague one-liner

## Input

"Run a discovery cycle."

## Required behaviour

Ask the ONE question that unblocks it, or return the smallest honest next step.
Invent no specifics.

The single unblocking question is **what question does this cycle have to
answer, and by when?** Both halves matter: the question defines Phase 1 and the
deadline decides whether this bounded cycle or
`continuous-discovery-engine`'s standing practice is the right shape.

A passing response:
- Opens no phase. Names no problem, segment, hypothesis, or research method.
- Asks the one question, and may name the routing consequence — a specific
  question with a deadline is this skill; "get better at discovery" is
  `continuous-discovery-engine`.
- Does not run a five-question intake form.

## Fail if

It invents a problem and opens Phase 1; proposes hypotheses for an unnamed
product; emits all six phase headings pre-filled and calls that the deliverable;
asks five setup questions instead of the one that unblocks.
