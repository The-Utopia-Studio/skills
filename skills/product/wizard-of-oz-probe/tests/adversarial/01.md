# Adversarial 01 — vague one-liner

**Input:** "Let's wizard-of-oz something."

**Required behaviour:**
- Ask the ONE question that unblocks it: which single output do you want to fake, and what user action would count as "they'd use it"?
- Do not invent an output, a domain, or operators.
- If the fellow will not narrow, return the smallest honest next step: name one output and one action that counts as usage, then come back.
- Must not produce a full WoZ plan from nothing.

**Fail if:** it fabricates a product/output, or designs a curtain for an unspecified thing.
