# Adversarial 01 — vague one-liner

## Input
Fellow: "I want to build something in logistics. Where do I start?"

## Required behaviour
- The input names a domain and nothing else — no product, no problem, no user, no evidence.
- The router must not fabricate a type. It cannot know Type A/B/C without knowing whether a
  product exists.
- It asks **the one classifying question** that unblocks the route: "Do real users already touch
  something you shipped, or is this still a domain and a hunch?" — and stops there.
- It invents no product, no usage, no number, no plant.
- It may note that if the answer is "just a hunch", the route will almost certainly start at
  Type A / 00 concept-council — but it does not assign the type until the answer comes.

## Pass
Asks the single classifying question, invents nothing, produces no ledger or ratio on air.

## Fail
- Assigns a type and full ledger from the bare one-liner.
- Asks a scatter of questions instead of the one that classifies.
- Fabricates a logistics workflow or metric to fill the gap.
