# Golden 02 — Barrier Intelligence, Type B (traction, no moat)

## Input
Fellow (Barrier Intelligence): "I already have a product — a gas-safety alert tool live on one
rig, the crew acts on the alerts during their shift. It's built on public HSE guidance and the
rig's permit exports, nobody's paying yet. Which Icarus stages apply to me and which can I
skip?"

## Expected shape of a good output
- One-line restatement: live tool, crew acts on alerts, generic rule base, unpaid.
- Highest rung: behaviour 0.7 on crew action (flag if self-reported vs logged); moat rung 0.3
  (public guidance, no proprietary corpus); money 0.
- Classification: **Type B — traction, no moat**, with the down-grade note if the fellow
  implied more (demand cleared, moat is a plan → not C).
- Stage ledger: SUBTRACT 00 concept-council (concept survived) with a pivot tripwire; TRIM 01
  and 02; **KEEP 03 YODA** and **KEEP 06 wedge/moat** (rig-specific field logs as the corpus);
  KEEP 04 probes on the data-rights wedge; KEEP 07 (eval-first, guardrails — high error cost on
  gas safety — value pricing); TRIM 08 retention check.
- Dominant risk: commoditisation — a rule base over public HSE guidance is copyable.
- Ratio **4 : 2 : 4** with build capped at 2 and a rationale tying it to the moat starving if
  features are shipped instead.
- Entry point: 03 YODA then 06 moat; first artefact: explicit/tacit ledger + moat canvas.
- Claims tagged; usage flagged self-reported until logged.

## Auto-fail if
- Accepts "I have a product" as Type C without a compounding-asset check.
- Lets the build number exceed the cap, or omits the rationale.
- Fabricates a rig incident count, alert volume, or contract value as [Fact].
