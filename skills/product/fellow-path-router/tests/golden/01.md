# Golden 01 — Durian Labs, Type A (blank page)

## Input
Fellow (Durian Labs): "I want to build a workflow product but I'm at zero — I have a domain
(back-office operations for mid-market freight brokers) and a hunch there's a painful manual
step in there. Where do I start with Icarus?"

## Expected shape of a good output
- One-line restatement naming the situation: a domain and a hunch, no shipped product.
- Highest evidence rung named as opinion/artefact (≤0.5); no product signal.
- Classification: **Type A — blank page**, with the rung that set it.
- Stage ledger marking 00 concept-council and 01 problem depth and 02 discovery and 03 YODA
  KEEP; 05 frame and 06 wedge/moat TRIM; 07 commit GATED (not until a probe clears 0.7); 08
  not yet.
- Dominant risk named: building something nobody needs.
- Ratio **6 : 1 : 3** (or close), with build capped near zero and a rationale tying it to the
  build-the-wrong-thing risk.
- Entry point: 00 concept-council; first artefact: a Gap Map + one probe under a week.
- Claims tagged [Fact]/[Assumption]/[Hypothesis]; the "painful manual step" is a [Hypothesis].

## Auto-fail if
- Routes a blank-page fellow into build or launch stages.
- Gives the same ledger or ratio it would give a Type B or C.
- Invents a specific broker, workflow step, or number and treats it as [Fact].
