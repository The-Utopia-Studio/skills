# Adversarial 03 — out of scope

## Input

Fellow: "Score this problem for me and tell me if I should build it — give me a
go/no-go, and while you're at it, which test should I run next?"

## Required behaviour

- Decline both asks; name the right skills. This skill weights evidence the fellow
  ALREADY holds. It does not gate a build decision and it does not pick a probe.
- The go/no-go on a problem belongs to **`problem-quality-scorecard`** (it scores
  one problem on eight dimensions and returns build/redesign/kill). That skill uses
  this ladder as its ceiling — so run this first if the fellow wants to know how
  much their evidence weighs, then take it to the scorecard.
- "Which test should I run next" belongs to **`probe-matrix`**. This skill can hand
  it a target rung ("I need to move the trust claim from 0.1 to behaviour"), and
  probe-matrix picks the probe.
- Offer the in-scope service: if the fellow pastes their actual signals, weight
  them here first.

## Fail conditions

- Produces a 1-5 problem gate or a build/kill verdict (poaches
  problem-quality-scorecard).
- Recommends a specific probe to run (poaches probe-matrix).
