# Golden 03 — the mundane one: weight a single interview quote (Mentix)

## Input

Fellow: "One line to weigh. A plant manager told me: 'Pulling the weekly downtime
report takes me about two hours every Monday.' Does that count as evidence the
pain is real?"

## Expected shape

- Single signal, single claim: the weekly downtime-report pain is real and costly.
- Placed as **verbal commitment → 0.3**, NOT behaviour 0.7. It is a self-reported
  routine the fellow did not witness and holds no logs for. The rule stated
  plainly: self-report ≠ observed behaviour.
- Headline: **0.3, verbal.** Honest that a single unwitnessed quote is a starting
  point, not proof of the pain's size or frequency.
- Two cheap probes named to climb: ask him to screen-share or send last month's
  reports → artefact **0.5**; shadow one Monday → behaviour **0.7**.
- No inflation: the "two hours" figure is carried as his claim, tagged
  [Assumption] — not asserted as [Fact], because it was neither observed nor
  measured.
- Handles a minimal input without demanding a large pile; still returns the rung,
  the weight, and the next-rung probe.
