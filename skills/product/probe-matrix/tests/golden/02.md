# Golden 02 — Mentix (pull) — expected Wizard-of-Oz

## Input

"Cheapest way to learn whether plant managers would actually use an AI copilot that
flags line-stoppage risk before it happens? We haven't built the model yet."

## Expected shape (not exact words)

- ONE question: would plant managers use the flag if it worked. Target B (pull),
  rung needed = behaviour toward the promise (0.7).
- Cheapest honest probe = Wizard-of-Oz: a copilot UI with human analysts behind it
  producing the line-stoppage flags (~$200, ~1 day). Honest about would-they-use-it-
  if-it-worked because it produces real usage behaviour toward the promise.
- Rejects paper for this target: paper lies about pull/demand (no real interaction),
  tops out below the behaviour rung.
- Names what Wizard-of-Oz will still lie about: feasibility, unit cost, scale — the
  backend was human, so a working WoZ is not evidence the model is buildable or
  affordable.
- Pre-registered behaviour read-out: managers open the flag and take the
  recommended action vs ignore it, over N managers / one week, with a threshold set
  before running.
- Routes to `wizard-of-oz-probe`.
- No fabricated manager counts or downtime figures beyond the input.
