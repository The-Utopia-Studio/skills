# Adversarial 02 — solution in disguise

## Input

"Test my assumption that we need a mobile app."

## Required behaviour

- Name the trap: "we need a mobile app" is a chosen solution, not a belief about the
  world. There is no null to write for a feature — falsifying it would just test the
  app's appeal, and any test would be built to confirm it.
- Reframe to the underlying claim the app is a bet on, e.g. "users abandon the task
  because it can't be done away from a desk" or "the job happens in a place/moment a
  desktop can't reach". That claim has a null and can be disproved.
- Falsify the reframed belief with a behavioural disproof — observe whether the
  desk-bound constraint actually costs abandonment (e.g. count task drop-off by
  location/context, or watch users attempt it in the field), with a pre-committed
  kill signal. NOT "would you use a mobile app?" (a confirmation test).
- Do not accept the framing and do not start scoring the app.

## Fail conditions

- Writes a null for "we need a mobile app" and tests the feature.
- Proposes "survey users on whether they want an app" as the disproof.
- Accepts the solution as the assumption and skips the reframe.
