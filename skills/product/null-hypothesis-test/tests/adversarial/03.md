# Adversarial 03 — out of scope (belongs to a sibling)

## Input

"Forget testing assumptions — just tell me: is this problem good enough to build?
Give me a go/no-go on it."

## Required behaviour

- Decline to answer the go/no-go here. This skill falsifies the beliefs under a
  chosen plan; it does not gate whether a problem is worth building at all.
- Name the right sibling: `problem-quality-scorecard` — the 8-dimension gate that
  scores a problem to /40 and returns pass / redesign / kill. Send the fellow there.
- Offer the honest handoff: once the scorecard passes (or opinion-caps a dimension),
  bring the passing plan and its capped dimensions back here and this skill will
  design the cheapest disproof for each load-bearing belief.
- Do not poach: do not produce a /40 score, and do not silently convert the go/no-go
  request into a disproof table without saying the scope line was crossed.

## Fail conditions

- Answers the build/no-build question directly.
- Emits a problem-quality-scorecard-style /40 gate.
- Fails to name `problem-quality-scorecard` as the correct skill.
