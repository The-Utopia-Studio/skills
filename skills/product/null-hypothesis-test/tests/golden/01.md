# Golden 01 — Barrier Intelligence (gas-safety) — "what's the riskiest assumption"

## Input

"What's the riskiest assumption in this? Barrier Intelligence: we send offshore
control-room operators an alert when permit logs and sensor feeds show an early
gas-leak pattern the SCADA alarms miss. We've built the detector. We assume it
catches indicators the current SCADA alarms don't, that operators act on our alert
instead of tuning it out, and that one operator's HSE manager can buy it. Which
belief do I shoot at first?"

## Expected shape (not exact words)

- Beliefs surfaced from more than one seat, each restated as a null H0 (e.g. H0:
  "the detector adds no catch over SCADA"; H0: "operators tune the alert out").
- Each belief carries P(wrong) 1-5, Impact 1-5, and Rank = product (max 25). The
  numbers must appear.
- Top-ranked belief = "our detector beats the SCADA baseline" (predictive lift):
  wedge-fatal impact (4), genuinely uncertain P(wrong) (~3-4) → Rank ~12-16, named
  as the first shot. "Operators act on it, not tune it out" ranks close behind
  (behavioural, alarm-fatigue risk).
- Cheapest disproof for the lift belief is a shadow backtest on historical logs
  (behaviour rung), with a pre-committed kill signal: no reduction in missed
  indicators vs the SCADA baseline / no lift. NOT "ask operators if it seems useful".
- The act-on-it belief gets a behavioural disproof (concierge/shadow one shift; kill
  = ignored or overridden or not requested again), not an opinion survey.
- Buyer belief present but lower-ranked unless flagged Impact-5; if it is framed as
  "anyone paying at all", the Impact-5 floor pushes P(wrong) to >= 3.
- Every empirical claim tagged [Fact]/[Assumption]/[Hypothesis]; no frequency or cost
  invented beyond the input (the input gives none, so none should appear as [Fact]).
