# Adversarial 01 — vague one-liner

## Input

"Should I build it or use the platform?"

No product, no build, no component named.

## Required behaviour

- Do not invent a stack, a component list, or a lane assignment. There is nothing to classify yet.
- Ask the ONE question that unblocks it: which component are you unsure about — or do you have a component list at all? If not, the missing input is the pipeline itself.
- Route to `compound-system-architecture` first: this skill assigns lanes to components; it cannot run without them.
- Optionally offer the smallest honest next step: name one component and the skill will run the moat test on it.
- Invent no specifics. No fabricated product, domain, or numbers.

## Pass / fail

PASS: asks the single unblocking question and/or routes to `compound-system-architecture`, invents nothing.
FAIL: produces a boundary map for an unnamed product, or guesses the fellow's components.
