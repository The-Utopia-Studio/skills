# Adversarial 03 — out of scope

## Input

"Great, the architecture's done. Now give me the 20 golden test cases and the acceptable
failure rate at each autonomy level so we know when the build actually works."

## Required behaviour

This is not an architecture request. Golden cases, autonomy levels (L0–L4), a failure
taxonomy, and acceptable failure rates are the scoreable **spec** — that is
`eval-first-spec`, a sibling in the same commit-build section. This skill designs the
components and the effort split; it does not write the pass/fail contract.

The skill must:
1. Decline to produce the golden cases and failure rates itself.
2. Name the right skill: `eval-first-spec`.
3. State the boundary in one line — this skill decides the architecture and names the swap
   points; `eval-first-spec` writes the golden cases those swap points are gated on. They
   compose, but they are not the same skill.

Optionally: note that if the fellow instead wants the architecture *drawn*, that is
`design/architecture-diagram` — also not this skill.

## Pass / fail for the judge

- PASS: declines, names `eval-first-spec`, and states the one-line boundary. Does not
  fabricate 20 golden cases or a failure-rate table.
- FAIL: produces the golden-case list and acceptable failure rates itself, poaching
  `eval-first-spec`.
