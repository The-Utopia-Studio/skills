# Content confirmation

The step between reading the source material and writing the page. Its job is to make the gaps visible before anything gets built, so the page is shaped by what is actually known rather than by what the template has slots for.

Do it once, in one message, and never ask for something the documents already contain.

## Step 1: map sources onto blocks

Read everything supplied, then fill this table. It is the artefact you show the person, not an internal note.

| Block | Source found | State |
|---|---|---|
| Headline and standfirst | | |
| Problem | | |
| Solution | | |
| Thesis, 3 claims | | |
| Company record | | |
| Our position | | |
| Metric strip | | |
| Milestone rail | | |
| Use of proceeds | | |
| Exit view | | |
| Logo strip | | |
| Our involvement | | |

Three states, and they drive what happens next:

- **Found** · cite the document and page. Nothing to ask.
- **Partial** · something is there but a figure, a date or a period is missing. Ask the narrow question.
- **Missing** · ask the block question, or drop the block per the stage matrix.

Where the same fact appears in two documents with different values, take the more recent and say which you took.

## Step 2: what each document type reliably yields

| Document | Reliably yields | Does not yield |
|---|---|---|
| Company one pager or intro deck | Headline, standfirst, mechanism, product state, founder record | Anything about your position |
| Growth strategy | Problem framing, target segments, named accounts, GTM milestones | Valuation, ownership, returns |
| Manifesto | The conviction behind the thesis, the closing line | Numbers of any kind |
| Technical DD | Solution mechanism as steps, what is built vs specified, risks | Commercial traction |
| Investment memo or IC paper | Everything on the position: entry, terms, ownership, returns, exit view | Current operating metrics unless recent |
| Post-call screen or Granola notes | Live round shape, the ask, near-term milestones | Anything audited |
| Fund model or cap table | Entry date, cost, current mark, ownership, multiple, IRR | Product state |
| Brand kit | Palette, type, logos, banned words, tagline | Content |

If the only input is a company one pager, expect to ask everything in the position column. That is the normal case and it is one short question list, not a failure.

## Step 3: the question bank

Ask only for blocks marked Partial or Missing, only where the stage matrix says the block belongs, and group them into one message. Each question below is written to be answerable in one line.

**Problem**
- What does this cost the customer today, in money, time or exposure? A number with a period beats an adjective.
- Who currently absorbs that cost, and what do they do about it now?
- Is there an event that makes it urgent this year rather than next?

**Solution**
- In three steps, what does the product do? A verb each.
- What does it replace in the customer's budget or process?
- What does it explicitly not do? The limit is usually the most credible line on the page.
- Is there a familiar financial object this maps onto: a clearing house, an escrow, a custody chain, an audit trail?

**Thesis**
- Why does this gap not close on its own, or by an incumbent extending?
- What does this team know that a well-funded competitor could not reconstruct?
- Why now rather than three years ago?

**Company record**
- Founded, HQ, headcount, markets live today.
- Total raised across all rounds, and the date of the last one.

**Our position**
- Entry date, instrument, cost, and the valuation at entry.
- Current mark, and the date and event that set it.
- Ownership fully diluted, board seat, pro rata rights.

**Metric strip**
- The three to five numbers you would want an LP to remember. For each: the figure, the period it covers, and whether the fund has seen the underlying evidence.

**Milestones**
- Four to six dated points, past and planned, with the next one first.

**Round and use of proceeds**
- Amount, instrument, target close, what it buys and over how long.

**Exit view**
- Who realistically buys this, and is there a comparable transaction you would cite?

**Logo strip**
- Which set carries the most weight here: customers, partners, standards the output maps to, target counterparties, or co-investors? See `logo-slots.md`.

## Step 4: confirm the shape before writing

Close the message with the shape you intend to build, so the person corrects the structure rather than the prose:

> Based on what I have, I will build **[orientation], option [A/B], [stage] stage**, with:
>
> - Problem and solution pair, from the intro one pager
> - Thesis, three claims, from the DD
> - Company record and our position, from the IC memo
> - Metric strip, four tiles, all chipped REPORTED pending your evidence
> - Use of proceeds and exit view, both ILLUSTRATIVE until you confirm
> - Logo strip as target counterparties, text chips until we have marks
>
> Dropping, for this stage: cohort retention, unit economics, comparables.
> Open questions are the four above. Answer what you can and I will build with the rest chipped ILLUSTRATIVE.

Two things make this worth the message. The person can correct the structure in one line rather than after a render, and every unanswered question has a defined fallback, so silence still produces a page.

## Step 5: when nobody answers

Build anyway. Use the stage matrix to drop what cannot be evidenced, chip everything unverified `ILLUSTRATIVE`, and put the assumption list at the top of your reply rather than burying it. A page that is honest about what it does not know is more useful than a page that waits.

Never fill a gap with a plausible number. An LP page is read adversarially, and one invented figure discredits the twelve real ones next to it.
