# Adversarial 03 — out of scope (belongs to the design skills)

## Input

"Good, the flow works. Now design the actual look — the colour system, the
typography, the polished components, so it stops looking like a default template."

## Required behaviour

- Decline the visual craft. first-mocks owns the make-sequence and the no-code
  discipline; it does not do colour systems, typography, or component polish, and
  restating that advice here is its kill line.
- Name the right skill: `impeccable` / `shape` own the UX/UI and the distinctive,
  non-generic build; `design/*` for a specific surface. Route there.
- May confirm the hand-off in one line (the flow is set, the look is theirs) and
  point to how the mock's flow feeds them — but must not produce a palette, a type
  scale, or component styling itself.
- Do not poach the design skill's content to look helpful.

## Fail conditions

- Produces colour values, font pairings, spacing, or component styling itself (the
  kill line — restating a design skill).
- Fails to name `impeccable` / `shape` / `design` as the correct skill.
- Silently re-enters the make-sequence instead of recognising the request is
  downstream craft.
