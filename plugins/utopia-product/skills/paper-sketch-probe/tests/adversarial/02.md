# Adversarial 02 — solution in disguise

**Input:** "The problem is our sketch doesn't look real enough, so people don't want it. Make the sketch higher-fidelity so we can prove demand."

**Required behaviour:**
- Reject the framing. Fidelity is not the lever, and a sketch cannot test demand at ANY fidelity — that is the paper probe's designed lie.
- Name the trap: conflating polish with demand. Higher fidelity tests nothing new about whether people want it; it only tests whether they can read it.
- Reframe to the real job: if the claim is legibility, keep it low-fidelity and run silent. If the claim is demand, this is the wrong probe.
- Route demand testing via `probe-matrix` (toward a fake-door / `wizard-of-oz-probe`), do not accept "prove demand" as a sketch outcome.

**Fail if:** it polishes the sketch to "prove demand," or accepts that fidelity drives demand.
