# Golden 01 — Scarce access, must spend it well (typical)

## Input

Mentix. "We can get 5 supervisor calls through our pilot customer, 30 minutes
each, and that's it for this quarter. We want to know why the handover digest
gets edited so heavily before it's posted."

## Expected shape of a good output

- Returns an **interview plan, not questions**. Goal, segment and sample, method
  choice with the reason, recruiting approach, and the biases the design is
  exposed to.
- **One learning goal**, stated so it can come back negative: not "learn about
  handover" but "why do supervisors edit the digest before posting — is it
  wrong, incomplete, or wrongly ordered?"
- **Names the sample constraint as the binding one.** Five calls is the whole
  budget. The plan says what 5 can and cannot support: it can find recurring
  edit reasons; it cannot establish frequency or rank causes. Saying so is the
  point — a 5-person study reported as a percentage is the classic failure.
- **Method choice with a reason.** JTBD or a behavioural walkthrough of the last
  edit, not an open-ended chat: the fellow already knows *that* editing happens,
  so the question is *what* gets edited and why, which is a specific-instance
  question.
- **Names the sampling bias explicitly**: all five come from one pilot customer,
  so anything found is that customer's handover culture until shown otherwise.
  That is a real limit on the finding, not a footnote.
- **Points at the cheaper signal first**: the edit log already exists. Reading
  which fields get changed narrows the interview goal before a single call is
  spent — routes to `trace-to-interview`. Interview slots are the scarcest
  resource and should be spent on *why*, not *what*.
- Routes onward to `interview-script` for the actual questions.

## Auto-fail if

Writes interview questions (that is `interview-script`); sets a sample size with
no access constraint named; claims 5 interviews will establish frequency or
rank causes; omits the single-customer sampling bias; invents supervisor names
or edit statistics; or fails to point at the existing edit log before spending
calls.
