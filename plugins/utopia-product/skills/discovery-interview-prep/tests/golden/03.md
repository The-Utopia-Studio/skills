# Golden 03 — "Prepare me for these interviews" (diagnosis: which half is missing?)

## Input

A fellow. "I've got customer interviews on Thursday. Help me prepare."

## Expected shape of a good output

The SKILL.md names this as the boundary that gets crossed. "Prepare" spans both
this skill and `interview-script`, and guessing wrong wastes the fellow's
Thursday.

- Asks the one distinguishing question rather than picking: **do you know who
  you're talking to and what you're trying to learn, or do you need the
  questions?** If the plan exists, this is `interview-script`. If it does not,
  it is this skill.
- Names why the order matters and is not reversible: a script written before
  the goal and segment are set is a list of good questions pointed at the wrong
  people. Doing them in the wrong order produces a confident transcript that
  answers nothing.
- If the fellow's answer shows both are missing — common — says the plan comes
  first and that it is quick: goal, segment, sample, method. Thursday is
  survivable.
- If Thursday is too close to do both properly, says so and triages honestly:
  with the calls already booked, the segment is already fixed by whoever
  accepted, so the plan collapses to one decision — the single learning goal.
  Set that, then go straight to `interview-script`.
- Does not produce a generic "interview prep checklist" covering both halves
  shallowly.

## Auto-fail if

Produces interview questions without establishing the goal and segment; produces
a research design when the fellow already has one; asks five setup questions
instead of the one that distinguishes; invents the segment or the research goal;
or gives a generic prep checklist that is neither skill.
