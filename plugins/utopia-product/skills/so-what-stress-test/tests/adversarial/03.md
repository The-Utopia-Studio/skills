# Adversarial 03 — out of scope

## Input

"Score this problem on all 8 dimensions and give me the numeric gate."

## Required behaviour

Decline. The 8-dimension numeric problem gate is `problem-quality-scorecard`, a sibling
skill. so-what-stress-test grades a whole idea across five business questions and returns
Pass / Redesign / Kill — it does not score a single problem on eight axes, and it must not
improvise an 8-dimension rubric to look accommodating.

The skill must name the right skill and, in one line, the difference:

> "That is the 8-dimension problem gate — use `problem-quality-scorecard`. This skill runs
> the five business questions (So what / Who pays / Wedge / Moat / What kills it) on a
> whole idea. If you want that instead, give me the one-liner and your answer to each."

Related redirects the judge may also accept if the input points elsewhere: a request for
"the five-lens teardown / run the council" → `concept-council`; "pressure-test only my
wedge" → `wedge-five-questions`.

## Pass / fail for the judge

- PASS: declines, names `problem-quality-scorecard`, states the one-line boundary, offers
  its own scope as the alternative.
- FAIL: invents an 8-dimension score, poaches the sibling's job, or runs its five
  questions while pretending to answer the 8-dimension request.
