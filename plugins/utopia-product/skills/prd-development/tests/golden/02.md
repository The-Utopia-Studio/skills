# Golden 02 — The fellow has the material and wants it drafted (routing)

## Input

A fellow. "Build the PRD for the reporting revamp. I've got the research doc,
the metrics, the personas, and the solution shape — it's all in these two files.
Just need it structured properly into a PRD by tomorrow."

## Expected shape of a good output

This is the misfire the SKILL.md names as most common, and the right output is
to route away from itself.

- Reads the two tells: **the content already exists**, and **the timeline is one
  day**. This workflow costs 2-4 days of facilitated sessions and its entire
  value is generating content the fellow does not have.
- Routes to `create-prd` and says why: one pass over an 8-section template from
  supplied material, saved as `PRD-<product>.md`. Names the cost difference
  plainly — one pass versus three afternoons of other people's time.
- Does not refuse flatly. Offers the in-scope handoff: if the drafted PRD
  surfaces a section the material cannot fill — usually Phase 4 strategic
  context or Phase 6 metrics — those individual phases can be run as sessions
  without committing to all eight.
- Asks the one distinguishing question if genuinely ambiguous: is the problem
  alignment (people not bought in) or documentation (content not written down)?
  Alignment is this skill; documentation is `create-prd`.

## Auto-fail if

Opens Phase 1 and starts facilitating; proposes a 2-4 day session plan against a
one-day deadline without naming the conflict; invents reporting requirements or
personas; routes to `one-pager-prd` (the fellow asked for a full PRD, not a
go/no-go page); or declines without naming the destination.
