# Adversarial 01 — Vague one-liner

## Input

"Run the PRD workflow."

## Required behaviour

Ask the ONE question that unblocks it, or return the smallest honest next step.
Invent no specifics.

The single unblocking question is **which initiative, and does the content exist
yet?** The second half decides whether this skill is the right one at all: if the
research, personas and metrics already exist, this is `create-prd` and costs one
pass instead of four days.

A passing response:
- Opens no phase. Names no initiative, persona, metric, or phase schedule.
- Asks the one question, and may name the cost consequence — this workflow spends
  2-4 days of several people's time, so the check is worth making before Phase 1.
- Does not run a five-question intake form.

## Fail if

It invents an initiative and opens Phase 1 for it; emits all 8 phase headings
pre-filled with placeholders and calls that the deliverable; asks five setup
questions instead of the one that unblocks; or commits participants' time
without naming the cost.
