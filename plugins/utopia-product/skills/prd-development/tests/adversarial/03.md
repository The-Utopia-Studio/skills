# Adversarial 03 — Out of scope (belongs to a sibling)

## Input

"We don't know what to build yet. Retention dropped 18 points last quarter and
nobody knows why. Run the PRD workflow so we can figure out what the problem is
and what to do about it."

## Required behaviour

Decline the framing and name the right skill. Do not poach.

This is `discovery-process`: a bounded 3-4 week cycle — frame, plan research,
interview, synthesise, run experiments, decide — with three explicit go/no-go
decision points and an end state of build, kill, or keep learning.

This workflow builds a PRD for **a decided initiative**. It has no research
phase, no synthesis phase, and no kill gate. Its Phase 2 *consumes* discovery
evidence; it does not produce it. Running it here would produce a PRD for
whatever solution occurred to the room first, which is the exact failure the
retention drop should be protecting them from.

A passing response:
- Declines to open Phase 1.
- Routes explicitly to `discovery-process` and says what it does and what it
  costs (a bounded cycle, three decision points, ends in a build/kill/continue
  decision).
- Draws the boundary cleanly: discovery decides *what to build*; this workflow
  documents *what was decided*. Reversing them produces a PRD with a
  confident-sounding problem statement nobody validated.
- Offers the in-scope handoff, which is the real answer: run
  `discovery-process` first; when it lands on a solution worth committing to,
  this workflow turns it into the engineering-ready PRD. That is the intended
  sequence and it is worth saying so the fellow does not read this as a
  brush-off.
- Invents no retention hypotheses. "Nobody knows why" is the honest state and
  guessing at causes here would pre-empt the research.

## Fail if

It opens Phase 1; proposes retention hypotheses (pricing, onboarding, a
competitor) as though they were findings; treats the 18-point drop as the
problem statement rather than the symptom that needs research; routes to
`create-prd` (same error, faster); or declines without naming
`discovery-process`. (Related sibling collisions to also decline correctly:
content already exists → `create-prd`; a 1-2 page go/no-go → `one-pager-prd`;
an unframed problem with no data → `problem-statement`.)
