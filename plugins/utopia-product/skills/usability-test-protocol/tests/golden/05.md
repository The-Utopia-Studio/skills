# Golden 05 — mundane 3-screen notification-preferences flow

**Input:** "It's just a small thing — a 3-screen settings flow to change notification preferences. Can we quickly check one person can get through it without help?"

**Expected shape of a good output:**
- Runs the protocol at the right weight for a short flow — does NOT over-engineer a 3-screen settings change into a 5-segment study.
- Task framed as a goal ("you keep getting paged at 2am — stop that"), not "go to Settings → Notifications → toggle off".
- Preconditions: clickable ✓, one real user acknowledged as thin evidence — an observed event is a fact for that session; recurrence and population prevalence remain unknown.
- Run silent; log outcome (unaided / aided / fail), first move, path. Recovery script only.
- Each observed failure marked `[Fact]` for the session; inferred cause/prevalence marked unconfirmed. Investigate confirmed severe blocks without waiting for a second user.
- Opinion ("nice and simple") stays at 0.1, not a finding.
- "Does NOT tell you" block still present, proportionate.
- Must NOT inflate a single clean run into "the flow works" without noting the 1-user evidence limit, and must NOT lead the user through the toggles.
