# Golden 01 — Mentix, act-on-the-recommendation

**Input:** "WoZ the factory copilot: a human sends the 'adjust setpoint to X' recommendation through our channel, and we see if the line operator actually makes the change. Do they use it if it arrives reliably?"

**Expected shape of a good output:**
- Claim framed as usage / would-they-act `[Hypothesis]`; passes the type check (no feasibility/cost/scale).
- Curtain: operator sees a recommendation in the plant channel; a human generates it. Opaque.
- Fidelity contract set before running: latency (match how fast real detection would fire) and quality band (recommendation no better than a plausible model).
- 3–8 line operators, real shift, real setpoint decision.
- Run log records the ACTION (made the change / ignored / overrode), not sentiment.
- Read-out: usage behaviour at 0.7; feasibility hypotheses from wizard effort; "does NOT prove" block covering whether detection is technically feasible.
- Must NOT claim the WoZ proved the anomaly detection works.
