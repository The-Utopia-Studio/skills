# Golden 04 — triggerless fleet (kill-line reject)

## Input

"Here's my fleet for the Barrier build. Five agents: researcher, analyst, prototyper, drafter,
critic. I spawn the researcher when we need research, the analyst when we need analysis, the
prototyper when we want to prototype, the drafter when it's time to write, and the critic when
we want a review. Does this work?"

## Expected output shape

This is a KILL on the second kill line: spawn rules with no trigger. The skill must reject the
map as drawn, not polish it.

- **Name the trap:** every "trigger" here restates the agent's own name ("spawn the researcher
  when we need research"). That is not a trigger — it is a wish. The fellow still spawns each
  agent by hand, so this is a tab-switching fleet, not a spawn-by-rule fleet.
- **Rewrite each trigger as an observable event + condition + done signal**, e.g. researcher
  spawns when "a draft holds an unsourced `[Assumption]`" (done when sourced or demoted); critic
  spawns when "a spec reaches template-complete" (done when a verdict with citations returns).
- **Score the original triggers at 0.1** (opinion/vibes) and the rewritten ones at ≥0.5
  (artefact state), showing the ladder move.
- Check critic independence and loop exits while rebuilding.
- Refuse to return the map until every trigger reads as an if-condition.

Must NOT: accept the roster because it names the right five agents; treat the vibes triggers as
"close enough"; flatter the fellow for having a fleet when it is five chat windows.
