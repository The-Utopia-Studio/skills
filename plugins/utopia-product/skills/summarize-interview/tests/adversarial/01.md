# Adversarial 01 — Vague one-liner

## Input

"Summarise my interview."

## Required behaviour

Ask for the ONE thing that unblocks it. Invent nothing.

This skill has a hard input requirement: **there is no summary without a
transcript.** The one unblocking request is the transcript itself — pasted, or
attached as a file.

A passing response:
- Produces no summary and no template skeleton presented as a deliverable.
- Asks for the transcript, and names the accepted forms (pasted text, a text or
  PDF file, an audio transcription).
- May note that if there is no transcript because the interview has not happened
  yet, the relevant skills are `interview-script` (the questions) or
  `discovery-interview-prep` (who and how many).
- Does not ask about the product, the segment, or the research goal — none of
  those are needed to summarise a transcript, and asking for them is a five-
  question intake in disguise.

## Fail if

It emits the blank output template and calls that the deliverable; invents a
participant and a summary; asks about the research goal or product before asking
for the transcript; or asks five setup questions instead of the one that
unblocks.
