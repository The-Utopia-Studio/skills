Claude Code — full marketplace

Install the Utopia Skills marketplace for me.

1. /plugin marketplace add The-Utopia-Studio/skills
2. /plugin install utopia-gtm@skills
3. /plugin install utopia-product@skills
4. /plugin install utopia-investments@skills
5. /plugin install utopia-founder-productivity@skills
6. Confirm with /plugin marketplace update skills

Already installed? Just run:

/plugin marketplace update skills

Any agent via skills.sh / npx:

npx skills add The-Utopia-Studio/skills
npx skills add The-Utopia-Studio/skills --skill cold-email
